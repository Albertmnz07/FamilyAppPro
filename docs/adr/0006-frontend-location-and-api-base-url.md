# Front-end in this repo, API by absolute URL, single-artifact deployment

The React + TypeScript front-end lives in `apps/frontend/` alongside the Spring Boot back-end in `apps/backend/` (a single Maven module under `apps/`, with no monorepo workspace tooling; layout amended by ADR-0010). In development the front-end reaches the API by absolute URL — `VITE_API_BASE_URL`, defaulting to `http://localhost:8070/api/v1` — trading proxy configuration for one environment variable. In production `apps/backend/pom.xml` builds `apps/frontend/` during `prepare-package` and copies `apps/frontend/dist` into Spring Boot's static resources (`apps/backend/target/classes/static`), so one executable JAR serves both the API and the SPA from the same origin and no extra CORS configuration is needed.

**Consequences:** CORS stays limited to `GET`, `POST`, `PUT`, `DELETE` and `OPTIONS` with credentials disabled; `PUT` was added for the optional DNI-photo upload (see ADR-0007). Hosting the front-end on a separate origin remains a backend decision first, not a front-end switch.
